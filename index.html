Notes Template Guide:
Define dynamic buttons (e.g., E:Greeting-Hello [N]///How are you?).
• Use A-D for Main Page Outstanding Requirements.
• Use E-Z for Notes tab.
• Smart Lines: If a line contains [1]-[6] and its box is empty, that whole line is automatically removed.
• Line breaks: // for new line, /// for 2 new lines.
• Tags (Main Info): [N] Name, [S] Soli, [W] WC, [R] RC, [D] Date, [L] LCHTERM.
• Tags (Req Details): [T1] Contract Lvl, [T2] Comm Sched, [T3] Direct Upline.
• Tags (Notes Tab): [1] to [6] for Values.
